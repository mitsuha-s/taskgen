# Prompts

В этой папке находится весь текст, который напрямую управляет LLM-пайплайном Вариантора.

## Как работать prompt engineer

1. Выбирайте активную версию пайплайна: сейчас это `task_processing_pipeline_v2`.
2. Меняйте только `.md` и `.html` файлы внутри версии пайплайна.
3. Если добавляете новый prompt-файл или переменную, обновите `manifest.json`.
4. Не храните секреты, ключи API и пользовательские данные в prompt-файлах.
5. После правок запускайте backend smoke-test с `LLM_PROVIDER=mock`, чтобы проверить загрузку manifest и переменных.

## Структура версии

- `manifest.json` - карта всех prompt-файлов, их переменных и назначения.
- `system_text.md` - системная инструкция для текстовых LLM-запросов.
- `system_file.md` - системная инструкция для LLM-запросов с файлом.
- `step1_file_to_html.md` - распознавание файла и перевод в HTML.
- `step2_parameters.md` - извлечение параметров задания.
- `step3_generate_variant.md` - генерация нового варианта.
- `step4_self_evaluate.md` - самооценка результата.
- `default_source.html` - демо-источник, если файл не загружен.
