# task_processing_pipeline_v1

Версия prompt-пайплайна, перенесенная из `old_variantor`.

## Шаги

1. `html_from_image`: получает изображение задания и возвращает полноценный HTML-документ.
2. `parameters`: получает один HTML-фрагмент задания и возвращает тип, класс и сложность.
3. `generation`: получает HTML-фрагмент, параметры и комментарий пользователя, возвращает новый HTML-вариант.
4. `self_evaluation`: получает исходный и сгенерированный HTML, возвращает оценку 1-10.

## Переменные

- `{{.TaskHTML}}` - HTML исходного задания или фрагмента.
- `{{.Params}}` - параметры задания в текстовом формате.
- `{{.UserComment}}` - комментарий пользователя к генерации.
- `{{.SourceHTML}}` - эталонный HTML.
- `{{.VariantHTML}}` - сгенерированный HTML.

Файлы объявлены в старом формате `manifest.json`.
