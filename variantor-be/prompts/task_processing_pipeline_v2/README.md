# task_processing_pipeline_v2

Версия prompt-пайплайна, перенесенная из `old_variantor`.

## Шаги

1. `json_from_image`: получает изображение задания и возвращает json.
2. `parameters`: получает один элемент списка json - задание и возвращает тип, класс и сложность.
3. `generation`: получает элемент списка json, параметры и комментарий пользователя, возвращает новый json-вариант.
4. `self_evaluation`: получает исходный и сгенерированный json, возвращает оценку 1-10.

## Переменные

- `{{.TaskJson}}` - json исходного задания или фрагмента.
- `{{.Params}}` - параметры задания в текстовом формате.
- `{{.UserComment}}` - комментарий пользователя к генерации.
- `{{.SourceJson}}` - эталонный json.
- `{{.VariantJson}}` - сгенерированный json.

Файлы объявлены в старом формате `manifest.json`.
